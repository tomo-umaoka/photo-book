# photo-book
AI generated web page using ChatGPT.

A simple showcase of what it can generate and to show off some photos. 

Please take as you need. To update the photos, upload all content under images folder and update script.js

At the top of the file of script.js, you will find a comma separated value. To add more photos, copy and paste another entry and update the file path. Then the website will auto adjust accordingly.

You can deploy this from github pages.
